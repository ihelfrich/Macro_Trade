
# Referee Checklist

## Identification Threats

- **Endogeneity of exposure**: Addressed by using shift-share and gravity IV designs.
- **Omitted variables**: Addressed by including fixed effects and control variables in the empirical models.
- **Measurement error**: Addressed by using multiple data sources and robustness checks.

## What would kill the paper

1.  Falsification tests fail (e.g., pre-trends are not flat).
2.  IV first stage is weak.
3.  Main results are not robust to alternative specifications.
4.  Theoretical model is shown to be internally inconsistent.
5.  The economic mechanism is shown to be irrelevant in the data.
